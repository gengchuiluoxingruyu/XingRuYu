# 文件搜索

本文件是 [[AGENTS]] 文件搜索章节的完整展开：规定 AI 在这个库里找笔记时的顺序、该搜什么、找不到时怎么回答。

>[!info] 定位
>- **先库内，后库外**：库内问题先在库内找，找不到就明说没覆盖，再考虑外部信息。
>- **语义与关键词并行**：两者结果按文件路径合并去重，再打开最匹配的几篇。
>- **已知的不再搜**：已经给出路径、已打开、已在本轮对话里出现过的笔记，直接读，不要重复检索。

## 1. 检索顺序

1. **已知路径**：笔记已附上、已打开、或前文提到过 —— 直接打开，跳过检索
2. **语义检索**：用 miyo 按意思找，适合"我记得写过但想不起标题"这类
3. **关键词检索**：按属性名、标签、引号里的原句、日期等精确词找
4. **合并**：按文件路径归并两边结果，取交集优先，再按相关度补足
5. **打开**：读最匹配的 2–4 篇全文，而不是只看摘要

## 2. 关键词该搜什么

| 线索 | 搜法 |
| --- | --- |
| 属性 | 字段名，如 `focus_hours`、`published` |
| 标签 | `tag:#regulation`、`tag:#daily` |
| 原文句子 | 引号里的原句，逐字搜 |
| 标题片段 | 记得的标题词 |
| 时间 | `2026-11`、`2026-11-16` |

## 3. 找不到时

- 明确说"库里没有覆盖到这个问题"，不要用常识冒充库内结论
- 外部话题才去查网络，并说明信息来自库外
- 检索工具报错时，退化为关键词检索继续找，不要反复重试同一个失败调用

## 4. 不许做的事

- 只凭记忆回答库内问题，不检索
- 同一个问题对同一工具反复重试
- 只读摘要就下结论，不打开原文
- 把无关笔记凑数，硬塞进答案

## 5. 自检

- [ ] 已给出路径的笔记没有重复检索
- [ ] 语义检索与关键词检索都跑过
- [ ] 引用了具体笔记路径，而不是笼统说"库里提到"
- [ ] 找不到时已说明没覆盖，没有编造
