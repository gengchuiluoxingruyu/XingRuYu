# 命名规则

本文件是 [[AGENTS]] 命名章节的完整展开：规定目录名、笔记文件名、属性名、标签名的写法，并列出库内已经存在、但按规定会被判为例外的现状。

>[!info] 定位
>- **文件名给人和工具看**：能一眼看出这篇是什么，不要缩写到看不懂。
>- **不同对象不同规则**：目录、笔记文件用英文大驼峰；属性名、标签名用英文小写。
>- **例外要写下来**：日记与剪藏按各自惯例命名，不算违规。

## 总则

| 对象 | 规则 | 例子 |
| --- | --- | --- |
| 目录 | 英文、大驼峰、单个单词 | `Regulation/` `Template/` `Cache/` |
| 笔记文件 | 英文、大驼峰、一到三个单词 | `Git.md` `PropertyGuide.md` |
| 属性名 | 英文小写、下划线连接 | `focus_hours`（见 [[Properties]]） |
| 标签名 | 英文小写、下划线连接 | `daily` `second_brain`（见 [[Tags]]） |
| 日记文件 | `YYYY-MM-DD.md` | `2026-11-16.md` |

## 逐条要求

- **用英文，不用中文**：目录名、新建的笔记文件名一律英文
- **大驼峰**：每个单词首字母大写，词间不加下划线、连字符、空格：`PropertyGuide`，不是 `property_guide`、`property-guide`
- **目录一个单词**：`Regulation`、`Template`，不写 `RegulationDocs`
- **文件一到三个单词**：`Tags.md`、`PropertyGuide.md`、`FileSearch.md`；超过三个词说明该拆成目录或改短
- **不带日期前缀**：除日记外，文件名不写日期，日期归 `created` 属性
- **不带版本号**：`xxx-v2.md` 不是新版本，是重复内容

## 例外与现状

| 场景 | 现行做法 | 说明 |
| --- | --- | --- |
| 日记 | `Log/DailyLogs/YYYY-MM/YYYY-MM-DD.md` | 按日期排序，不受大驼峰约束 |
| 剪藏 | 沿用原文标题，允许中文 | `Row/` 是原始素材，可追溯比规整更重要 |
| 模板 | `Daily.md` `Timestamp.md` | 与 `type` 取值对应，保持简短 |
| 配置与系统文件 | 按工具要求，如 `.obsidian/`、`.gitignore` | 工具约定优先 |
| `AGENTS.md` `README.md` `LICENSE` | 沿用通行写法 | 全大写或固定名，不改 |

## 改名的注意事项

- 在 Obsidian 里重命名，别在文件管理器里改，否则 wikilink 不会跟着更新
- 改名会改动其他笔记里的链接，属于批量修改，先说明影响范围再动手
- 剪藏与日记改名后，`title`、`date` 等属性要跟着对齐

## 自检

- [ ] 新建的目录是单个英文单词、大驼峰
- [ ] 新建的笔记文件名是英文、大驼峰、不超过三个单词
- [ ] 没有中文、空格、连字符、下划线（日记与剪藏除外）
- [ ] 文件名里没有日期和版本号
- [ ] 改名用了 Obsidian 的重命名，链接已同步
