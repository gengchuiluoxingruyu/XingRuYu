# 临时文件

本文件是 [[AGENTS]] 临时文件章节的完整展开：规定一次性脚本、备份、导出中间产物放在哪、留多久、怎么清。目的是让笔记库只留笔记，不留施工痕迹。

>[!info] 定位
>- **一律进 Cache/**：不在库根生成文件，不散落到笔记目录。
>- **用完即删**：`Cache/` 是工作台，不是档案库。
>- **备份别用 `.md`**：`.md` 备份会被当成笔记索引进来。

## 放哪

| 类型 | 位置 | 保留 |
| --- | --- | --- |
| 一次性脚本（PowerShell、Python 等） | `Cache/` | 用完即删 |
| 备份 | `Cache/`，文件名加 `.bak` 或 `.md.bak` | 确认结果无误后删 |
| 导出中间产物（CSV、JSON、图片切片） | `Cache/` | 用完即删 |
| 调试输出、日志 | `Cache/` | 用完即删 |
| 长期使用的工具脚本 | `Cache/`，文件名写清用途 | 保留，但要在文件开头注释用途 |

## 三条硬规则

- **不落库根**：库根只放 `AGENTS.md`、`README.md`、`LICENSE`、`.gitignore` 这类固定文件
- **不落笔记目录**：`Wiki/`、`Log/`、`Row/`、`Regulation/` 里不出现脚本与备份
- **备份必须改后缀**：`Notes.md` 的备份写成 `Notes.md.bak`，写成 `Notes-bak.md` 会被 Obsidian 当笔记、被检索当内容

## 为什么

- 笔记库会被 Obsidian 索引、被语义检索召回、被 Git 提交；临时文件混在里面会污染搜索结果、撑大提交历史
- 备份文件以 `.md` 存在时，会和原文形成重复内容，链接与检索都会指向两份
- `Cache/` 目录在权限表里是 `rwx`，AI 可自由读写，不需要每次申请，也没有理由写到别处

## 清理时机

- 任务结束前清一次：脚本执行完、导出确认无误后即可删除
- 备份保留到用户确认结果
- 中途失败需要排查时，可在 `Cache/` 留到问题解决，解决后删

## 自检

- [ ] 本次产生的脚本、备份、中间文件都在 `Cache/` 里
- [ ] 备份文件名带 `.bak`，不会被当成笔记
- [ ] 任务结束后 `Cache/` 里没有残留
- [ ] 库根与各笔记目录没有新增临时文件
