### 一、国际顶级 CTF（6 个）

|#|赛事|主办方|难度|特点|
|---|---|---|---|---|
|1|**DEF CON CTF**​|DEF CON（1996 年首届）|地狱级|"网络安全世界杯"，Attack-Defense 攻防模式，8 月拉斯维加斯决赛。2026 年资格赛 **686 支队伍**仅 12 支晋级|
|2|**Google CTF**​|Google 安全团队|困难级|Jeopardy 解题赛 + 攻防决赛，题目质量极高，另设面向新手的 Beginner's Quest|
|3|**PlaidCTF**​|CMU 的 PPP 战队|困难级|以难度高、打磨精细著称，冠军可直接晋级 DEF CON CTF 决赛|
|4|**picoCTF**​|卡内基梅隆大学|入门级|**全球公认的 CTF 入门首选**，免费、教育导向，配套全年开放的 picoGym 练习平台|
|5|**CSAW CTF**​|纽约大学 NYU Tandon|入门→进阶|全球规模最大的学生导向 CTF 之一，资格赛常有 1200+ 队伍，**奖金与奖学金总额超百万美元**​|
|6|**HITCON CTF**​|台湾 HITCON 社区|困难级|亚洲顶级赛事，以题目极难著称，亚洲黑客社群的核心赛场|

> **DEF CON 34 CTF 2026 最新战况**：冠军 **Blue Water**​ 国际联队（含清华网络研究院杨晶城、游宇凡，均来自清华蓝莲花战队），亚军韩国 KAIST 联队 **0 x 4 b 52**，季军韩美联队 SuperDiceCodeLovers。2026 年是 DEF CON CTF **首次允许生成式 AI 作为辅助工具**，官方称之为"CTF 的重大转折点"。

### 💡 ISCC 特别说明：新手最友好的入口

ISCC 的七个赛项中，有三个是**个人赛**，不用组队就能打：

|赛项|形式|说明|
|---|---|---|
|**破阵夺旗赛**​|个人赛|经典 CTF，题型含 BASIC、WEB、REVERSE、PWN、MISC、MOBILE|
|**无限擂台赛**​|个人赛|解题获得打擂资格，可提交**原创题目**取代擂台题|
|**数据安全赛**​|个人赛|用机器学习/深度学习建模并提交预测结果|
|博弈对抗赛 / 智能安全赛 / 创新作品赛|组队赛|—|

线上挑战赛持续 18–25 天，时间充裕，非常适合作为 CTF 的第一战。

### 按水平选赛：三条路径

#### 🟢 零基础（大一大二）

```
picoCTF / 蓝桥杯网络安全赛道（教育部白名单）
   ↓
ISCC 破阵夺旗赛（个人赛，25天，4-5月）
   ↓
XCTF 分站赛 / 百度杯 CTF
```

**主攻 Web 和 Misc 两个方向**——这是入门性价比最高的组合。

#### 🟡 冲保研 / 升学（大二大三）

```
全国大学生信息安全竞赛（CISCN）—— 网安方向第一硬通货
   ↓
ISCC 博弈对抗赛 / 创新作品赛
   ↓
强网杯 / 网鼎杯青龙组
```

#### 🔴 冲就业 / 进头部安全厂商

```
Real World CTF / DEF CON 资格赛 + 护网行动经历 + 国际认证
```

配套认证：**OSCP / CISSP / CEH**（国际）、**CISP / CISP-PTE**（国内政企项目准入）。

### 三个必须知道的实用信息

1. **CTFtime.org 是必备工具**——全球 CTF 赛事日历、战队排行榜和赛事权重评分（0–100 分，90+ 为精英级，50–89 为中高级）。几乎每个周末都有比赛，可按难度筛选。
2. **日常练习平台**：Hack The Box、TryHackMe、picoGym、OverTheWire（Bandit/Natas 系列 wargame）、VulnHub（可下载靶机）、Hacker 101 CTF。
3. **法律红线**：所有练习必须在**授权靶场**进行，未经授权的渗透测试违法——这是网安赛道不可逾越的底线。
